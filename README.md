# EduBot – AI-Powered Education Chatbot

## Overview
EduBot is an AI-powered education chatbot designed to help students get answers to educational questions through a conversational interface.

## Features
- AI-powered question answering
- Interactive Streamlit interface
- Educational assistance
- Google Gemini API integration

## Technologies Used
- Python
- Google Gemini API
- Streamlit
- Google Colab

## Project Files
- `app.py` – Streamlit application
- `requirements.txt` – Project dependencies
- `EduBot_Complete_Colab_and_Streamlit_Deployment.ipynb` – Complete development and deployment notebook

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## API Configuration
Configure your Gemini API key using Streamlit secrets. Never upload API keys or passwords to GitHub.
